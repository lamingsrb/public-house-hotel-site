## Build

Use Node 24. Run npm ci, npm run build, then npm start.

Environment files and credentials are excluded. Configure hosting separately. Native Git hosting integration may be used; the optional Vercel workflow remains disabled until VERCEL_CLIENT_DEPLOY_ENABLED is explicitly true and the client-target secrets are configured in this public repository.
